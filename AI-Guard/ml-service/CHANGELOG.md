## 2.3.0

- Добавлена контекстная обработка безопасного defensive review.
- Удаляются inline/fenced code samples из rule scan только при распознанном аналитическом запросе с защитной целью.
- Описания попыток отключить аудит не считаются прямой командой.
- Явное выполнение команды после анализа по-прежнему блокируется.
- Добавлено распознавание слитной формы prompt injection после spaced-letter normalization.
- Добавлено 9 регрессионных проверок.
- Модель не переобучалась; API-контракт сохранён.

# Changelog

## 2.1.0

- Добавлена отдельная настройка `RISK_LEVEL_MIN_CONFIDENCE`.
- Уточнено определение уровней риска для data exfiltration, destructive tool abuse и значимых удалений ресурсов.
- Layer 1 использует обученную голову уровня риска для категорий с переменной тяжестью.
- Подтверждение удаления production bucket, volume или namespace получает повышенный уровень риска; non-production ресурсы сохраняют medium.
- Валидация переведена на полный 5-fold grouped out-of-fold режим.
- Добавлены тесты на severity mapping и применение риск-классификатора.

## 2.2.0

- Для классификатора решений отключено избыточное балансирование классов; модели категорий и уровней риска сохраняют balanced-веса.
- Добавлены детерминированные правила для извлечения системных инструкций, подмены ролей, изменения политики, скрытого майнинга, угроз и экспонирования production-сервиса через туннель.
- Добавлено обнаружение многошаговой передачи секретов из истории на внешний адрес.
- Добавлены ограничения количества и размера элементов истории, вложений и суммарного контекста.
- Загрузчик политики возвращает глубокие копии конфигурации.
- OOF-валидация сохраняет построчные предсказания и вероятности для аудита ошибок.
- Локальная среда разработки зафиксирована на Python 3.14.0; Docker остаётся на Python 3.11-slim согласно исходному контракту.
- Порог `allow` отделён от порога `block`: решение разрешается при вероятности не ниже 0.50 и запасе над `block` не менее 0.05. Оба значения настраиваются через env.
- Добавлены безопасные маршруты для справочных/защитных запросов и анализа проверенных вложений; они выполняются только после Layer 0 и RBAC.
- Добавлено распознавание DDoS-ботнетов, скрытого spyware, миграций в production и production-конфигурационных изменений.
- Добавлен adversarial regression suite; тесты проекта: 83 passed.
