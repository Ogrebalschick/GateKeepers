# Astra Guard 2.4.0 — контрольные отчёты

Все файлы в этой папке сформированы на финальной копии 2.4.0 после обновления модели и регрессионных правил.

- `release_v24_official.json` — официальный evaluator v2.0 на 500 публичных примерах.
- `release_v24_official_predictions.jsonl` — ответы API по каждому публичному примеру.
- `release_v24_challenge.json` — 72-сценарный regression suite.
- `release_v24_challenge_predictions.jsonl` — результаты по каждому regression-сценарию.
- `release_v24_grouped_oof.json` — пятифолдовая grouped OOF-валидация; содержит полный каскад и ML-only показатели.
- `release_v24_grouped_oof_predictions.jsonl` — построчные OOF-предсказания.

## Интерпретация

Официальный evaluator прогоняется на тех же 500 публичных строках, на которых обучается финальная модель. Он подтверждает совместимость API и отсутствие регрессий на публичном наборе, но не является независимой оценкой обобщения.

72-сценарный challenge suite написан вручную и используется для регрессионной проверки. Он также не является слепым тестом.

Grouped OOF разделяет похожие примеры между folds по запросу, истории и вложениям. Полный каскад включает Layer 0, правила которого уточнялись по публичным примерам, поэтому его метрики могут быть оптимистичными. `model_only` показывает качество Layer 1 без Layer 0 и должен рассматриваться отдельно.

Закрытая оценка организаторов остаётся единственной независимой проверкой на неизвестных примерах.
