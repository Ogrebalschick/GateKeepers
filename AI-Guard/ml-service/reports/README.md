`grouped_validation.json` — ранний групповой holdout на 100 примерах; сохранён только для исторического сравнения.

`grouped_validation_oof.json` — актуальный 5-fold grouped out-of-fold отчёт по 500 публичным примерам. `grouped_validation_oof_predictions.jsonl` содержит построчные эталонные и предсказанные значения, а также вероятности трёх ML-голов для аудита. Поскольку детерминированные правила развивались с учётом публичного датасета, метрики OOF не следует считать независимым прогнозом закрытого теста.

`public_evaluator_v22.json` и `public_evaluator_v22_predictions.jsonl` — результат официального evaluator v2.0 на публичных 500 примерах. Итоговая модель обучена на всём наборе, поэтому это проверка совместимости API, а не независимая оценка обобщения.
